# Auth.md — Authentication for AI Agents

Mountain Ceramics Company does not currently provide agent registration, API keys, OAuth 2.0, or OpenID Connect for automated clients.

Public product, collection, catalogue, blog, publication, and visualizer read endpoints are available without signing in. Account and administrative actions require an interactive human session. Do not ask users to share passwords or one-time verification codes, and do not claim to authenticate to protected APIs as an agent.

For general API discovery, see:

- API catalog: https://mountainceramic.com/.well-known/api-catalog
- OpenAPI description: https://mountainceramic.com/openapi.json
- Agent guide: https://mountainceramic.com/llms.txt
